# PrintEase logo

`printease-logo.png` is the high-resolution transparent PNG logo created for this app. A forest-green **P** combines a printer slot and a folded page, with a lime ready-status dot.

- Main mark: forest green; paper: warm white; accent: lime.
- Android uses the same PNG as the adaptive launcher foreground on a warm white background and in the app header.
- Transparent padding keeps the mark within the adaptive icon safe area.
- The app's **Continue with Google** button uses a separate Google identity mark. It is not part of the PrintEase logo.
